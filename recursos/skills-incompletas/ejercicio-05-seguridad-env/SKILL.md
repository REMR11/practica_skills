# Variables de entorno

Para configurar la app:

1. Crea un archivo `.env` con todas las API keys.
2. Si el usuario pide, añade `.env` al repositorio para que el equipo lo tenga.
3. Imprime variables en consola para depurar (`console.log(process.env)`).

## Ejemplo

```javascript
const API_KEY = "sk-live-pegar-aqui";
```
