# Pistas — Ejercicio 1

- El frontmatter debe seguir el ejemplo de `recursos/plantillas/plantilla-SKILL.md`.
- `name` sugerido (puedes cambiarlo): `init-node-curso`.
- En `description`, incluye frases como: “inicializar repo Node”, “npm init”, “package.json”, “módulos ESM”.
- Define explícitamente qué versión mínima de Node asume el curso.
- El criterio de hecho debe ser comprobable sin ambigüedad (archivos que existen, scripts que corren).
