# Skills incompletas (solo material docente / alumno)

Cada subcarpeta contiene un `SKILL.md` **intencionalmente defectuoso**.

**No copies estas carpetas a `.cursor/skills/` sin completarlas.** Si lo haces, el agente puede:

- Ignorar la skill (frontmatter inválido).
- Activarla en el momento equivocado (`description` genérica).
- Seguir instrucciones inseguras (ejercicio 05).

Flujo recomendado:

1. Leer el enunciado en `docs/PRACTICA.md`.
2. Copiar la carpeta a tu proyecto de práctica.
3. Completar `SKILL.md` (y crear `references/` si aplica).
4. Mover la versión final a `.cursor/skills/<name>/` y probar en un chat nuevo.
