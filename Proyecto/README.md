# Generador de documentación IA

Aplicación Streamlit para transformar requerimientos informales en artefactos de negocio y técnica.

## Requisitos
- Python 3.10+
- Streamlit

## Ejecución local
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run main.py
```

## Pruebas
```bash
python -m pytest -q
```
