# practica_skills

Material de práctica para aprender **Agent Skills** en Cursor con proyectos **Node.js**.

## Contenido

| Ruta | Descripción |
| --- | --- |
| [docs/PRACTICA.md](docs/PRACTICA.md) | Teoría, checklist, **6 enunciados** y actividad opcional con `npx skills` |
| [recursos/plantillas/plantilla-SKILL.md](recursos/plantillas/plantilla-SKILL.md) | Plantilla vacía para nuevas skills |
| [recursos/skills-incompletas/](recursos/skills-incompletas/) | Seis skills **incompletas** + `PISTAS.md` por ejercicio |

## Inicio rápido (estudiantes)

1. Lee `docs/PRACTICA.md` de principio a fin.
2. Opcional: Actividad 0 (instalar una skill pública con Node y auditarla).
3. Trabaja los enunciados 1–6 en un repositorio Node propio; usa las skills incompletas solo como punto de partida.
4. Entrega según indique tu docente (repo + evidencia de activación en chat).

## Docentes

Las soluciones no se incluyen a propósito. Las pistas están en cada `recursos/skills-incompletas/ejercicio-*/PISTAS.md`.
